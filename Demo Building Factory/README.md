# Demo Building Factory

The Demo Building Factory contains prospect-specific demonstrations built from the Aureum CAP workflow. Each numbered project keeps its research, intelligence, opportunity hypothesis, brief, assets, website, deployment record, analytics status, and outreach boundary together.

## Projects

| Project | Prospect | Status |
|---|---|---|
| `001-Zoey-Vincent/` | Zoey Vincent Vevakpor | Website built; deployment and formal QA pending |

## Standard project structure

```text
001-Prospect/
├── research/
├── intelligence/
├── opportunity/
├── brief/
├── assets/
├── website/
├── deployment/
├── analytics/
└── outreach/
```

The factory is separate from the Client Acquisition Engine and CAP Command Center. No outreach is sent automatically from a factory project.
